# ESP32-touchscreen-using-c
This is an ESP32 touchscreen application built with:

Arduino: controls ESP32 startup and loop LVGL: creates buttons, labels, text areas, and screens LovyanGFX: sends graphics to the display and reads touch input PlatformIO: builds and uploads the project ArduinoJson: reads and saves configuration data EEZ Studio: generates the UI files inside

Main Program Flow

In main.cpp:

Contains your application logic.

main.cpp: ESP32 startup, display, touch, and main loop DynamicButtonManager.cpp: creates buttons and dynamic UI controls DynamicButtonManager.h: declares the DynamicButtonManager class CallBacks.cpp: handles received data and application events config_handle.cpp: loads and saves JSON configuration files
